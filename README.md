# 湛江国庆自驾 · 路线方案站（DEMO）

目的：把「方案A 南极村线」「方案B 湖光岩线」的**路程与时间事实**、**方案对比论证**、**可自由组合的路线计算**、**住宿与工具查询**放到一个网页里，供两家人共用。

- 状态：**演示版（未部署）**
- 数据更新：2026-09-29
- 行程窗口：2026-10-02 ~ 10-06（10/2 出发）

| 文件 | 说明 |


## 四、计算口径（重要）

- **里程与车时**：OSRM 路网实际路径计算（WGS84 坐标），非直线距离。
- **国庆预估时间**：纯车时 × 1.35（含拥堵与休息），可在自由组合页查看。
- **渡轮段**（东南码头 ↔ 硇洲岛）：按船程 20 分钟计入，**国庆排队 0.5-1.5 h 不计入驾驶时间**，页面单独标注。
- **每日驾驶上限**：默认 5 h，可切换 3/4/5/6 h；天数 = 国庆预估 ÷ 上限（向上取整），不含景点停留。
- **日出日落**：按经纬度天文算法计算（赤坎 10/2 日出 06:30 / 日落 18:26；南极村 10/3 06:32 / 18:27；硇洲岛 10/4 06:29 / 18:23）。

## 五、数据来源与不确定项

| 数据 | 来源 | 状态 |
|---|---|---|
| 里程/车时 | OSRM 路网计算 | 可靠，道路调整可能带来小偏差 |
| 日出日落 | 天文算法 | 可靠（±1 分钟） |
| 硇洲岛船票与排队 | 湛江本地宝（2024-01）、湛江市政府文旅页（2022） | **需现场核实**：快艇客船存在 16 元 / 25 元两种说法；时刻表随季节调整 |
| 东南码头停车费 | 湛江本地宝 | 约 30 元/天，需核实 |
| 湖光岩门票与开放时间 | 景区公开信息 | 约 50 元/人，07:00-18:30（18:30 停止入园） |
| 潮汐 | 潮汐表站点（湛江站） | 网页端只发布当月数据，10 月表需 10/1 后查；南极村需查徐闻/角尾站 |

| 高速免费 | 2026 国庆放假安排（10/1-10/7，7 座及以下免费） | 以官方公告为准 |

   - 当前 demo 的实现：提交后本机立即显示 + 存入浏览器 localStorage；页面同时展示「已整理留言」示例，演示整理后的呈现效果。
